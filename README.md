# 🗄️ Projeto de Integração e Análise de Dados com PostgreSQL

## 📌 Sobre o Projeto
Este projeto tem como objetivo realizar a integração, tratamento e análise de dados utilizando PostgreSQL, aplicando conceitos de ETL (Extract, Transform, Load).

Os dados foram organizados, tratados e estruturados para garantir qualidade e confiabilidade na análise.

---

## 🎯 Objetivos

- Integrar diferentes bases de dados
- Tratar inconsistências e dados nulos
- Padronizar formatos
- Criar estrutura relacional eficiente
- Preparar dados para análise

---

## 🧱 Arquitetura do Projeto

Pipeline de dados:

Coleta → Tratamento → Transformação → Armazenamento → Análise

---

## 🗄️ Banco de Dados

Utilizado o banco relacional

- Armazenamento estruturado
- Criação de tabelas relacionais
- Execução de queries analíticas
- Integração de dados

---

## 🔄 Processo ETL

### Extração
- Importação de dados de diferentes fontes

### Transformação
- Remoção de dados inconsistentes
- Tratamento de valores nulos
- Padronização de formatos
- Criação de novas colunas

### Carga
- Inserção no banco PostgreSQL
- Organização em tabelas relacionais

---

📊 Análises Realizadas

- Consolidação de dados
- Organização por entidades
- Preparação para consultas analíticas
- Base pronta para BI (Power BI, etc)

---

🛠️ Tecnologias Utilizadas

- SQL
